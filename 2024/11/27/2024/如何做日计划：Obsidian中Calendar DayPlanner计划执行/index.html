如何做日计划：Obsidian中Calendar+DayPlanner计划执行

发表于 2024-11-27 | 分类于 自我成长 | | 热度:

日计划的设定目标

  1. 时间设定区块为30mins，可根据自身需求选择15mins或者1h
    每个人的专注程度不一样，不必强求自己必须长时间进行同一件事

  2. 设定计划，同时希望反馈实际的完成情况。但不强求完全按照计划执行。
    忘记在哪本书上看到的，书里面提到的是做周计划，每周最重要的三件事，每天每时的计划事项，计划后还有一列，作为计划的实际执行情况，每周进行总结分析。感觉这个想法不错，所以我希望我的计划表中也要体现，实际执行和操作的情况

  3. 操作简单，计划和执行需要一目了然。

使用到的工具

  1. Obsidian自带的Calendar功能
  2. Day Planner插件：obsidian://show-plugin?id=obsidian-day-planner
  3. Dataview安装：obsidian://show-plugin?id=dataview
  4. 流水账中涉及到的Cmenu + QuickAdd，具体可见文章
  5. 苹果日历链接及timetrack（自由选择）：因为我同时会使用timetrack软件记录时间使用情况，所以也结合了这部分

页面展示

  1. 工作时的页面：
  • 底部有正在进行的事项以及即将到来的事项
  • 右侧左边可打钩的事项即为计划事项，右侧带有绿底时间的即为实际完成情况
  • 一条绿线为目前的时间线

![[Pasted image 20260707161713.png]]

  1. 近期安排：根据需求可查看3天的安排或者工作日或本周的安排

![[Pasted image 20260707161740.png]]

具体设置过程

1. Calendar的设定

Obsidian本身内置了Calendar的功能，如下。点击对应的日期即可新建当天对应的page，点击w下方的周数（即图片中的绿色字体），可建立周计划。

![[Pasted image 20260707161751.png]]

建立日记的时候，可提前设定好模版，在【日记】中可进行设置。

![[Pasted image 20260707161805.png]]

  1. 可直接设定对应的日期
  2. 设定当日的目标，这里我设置的是习惯的统计内容，详情可见
    https://mp.weixin.qq.com/s/Er7TEu4XQjJKw5n7R--HVQ

![[Pasted image 20260707161822.png]]

  1. 【今日安排】这个标题需要着重注意，在Day Planner中也会用到

![[Pasted image 20260707161841.png]]

2. Day Planner的设定

插件地址：obsidian://show-plugin?id=obsidian-day-planner

这里需要与每天日记中的标题一致，其他的根据自身需求调整

![[Pasted image 20260707161854.png]]

其他我的设置供参考：

![[Pasted image 20260707161908.png]]
![[Pasted image 20260707161914.png]]

我增加了Remote Calendar，主要是苹果手机里对应的日历链接，在日历中设置为公开日历，分享链接即可，然后自己设定颜色等

![[Pasted image 20260707161931.png]]
点击左边的【open Multt-Day View】即可打开最近的多日计划图表，右侧的这个小图标可进行天数的设置
![[Pasted image 20260707161943.png]]
![[Pasted image 20260707161952.png]]

也可进行视图的设置，大家自行探索

![[Pasted image 20260707162002.png]]

3. 操作过程

  1. 点击Calendar建立当天日记，在对应时间里设定计划
  2. 干什么时的时候点击cMenu中的流水账，具体设置参考xxx

大功告成！
