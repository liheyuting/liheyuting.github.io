日计划的设定目标

  1. 时间设定区块为30mins，可根据自身需求选择15mins或者1h
    每个人的专注程度不一样，不必强求自己必须长时间进行同一件事

  2. 设定计划，同时希望反馈实际的完成情况。但不强求完全按照计划执行。
    忘记在哪本书上看到的，书里面提到的是做周计划，每周最重要的三件事，每天每时的计划事项，计划后还有一列，作为计划的实际执行情况，每周进行总结分析。感觉这个想法不错，所以我希望我的计划表中也要体现，实际执行和操作的情况

  3. 操作简单，计划和执行需要一目了然。

使用到的工具

  1. Obsidian自带的Calendar功能
  2. Day Planner插件：obsidian://show-plugin?id=obsidian-day-planner
  3. Dataview安装：obsidian://show-plugin?id=dataview
  4. 流水账中涉及到的Cmenu + QuickAdd，具体可见文章
  5. 苹果日历链接及timetrack（自由选择）：因为我同时会使用timetrack软件记录时间使用情况，所以也结合了这部分

页面展示

  1. 工作时的页面：
  • 底部有正在进行的事项以及即将到来的事项
  • 右侧左边可打钩的事项即为计划事项，右侧带有绿底时间的即为实际完成情况

我自己的话大概是三个月瘦了15斤+，从去年10月开始，到今年年初，大概瘦了十多斤。正常饮食，运动量当时的确也蛮大的，我同事她瘦了六十多斤，因为我基数不大，最重时体重大概是118多点，现在是100左右，体脂率从30%+到现在的22%，最近几个月体重基本没什么波动，最多少了点脂肪，多了点肌肉。我也没想着再降体重啥的，想着就是再长点肌肉，再降低体脂率，偏好的体脂率大概是17%-19%之间。

大学的时候体脂率还有过13%、14%，那时候体重大概90斤左右，但仍然会感觉自己不算瘦，啊的确是，我之前从来没有过减肥什么的想法，也不限制自己吃，那时候可能年轻，加上喜欢爬山徒步一些运动，吃东西的话家里养成的饮食习惯都很清淡，自己也还算节制。等到工作后，脂肪就变多了，慢慢的17%，19%，21%，23%，等到疫情期间，压力加上饮食原因，暴涨到30%+。直接重了十多斤。最关键的是，我失去了对身体的把控力，感觉自己走路气喘吁吁，羽毛球没怎么打，心跳的就好厉害，好多运动都感觉到自己的力不从心。坦白说，这种感受并不好，曾经写东西说，“腐朽的肉体紧紧踩住灵魂的脚后跟，步履蹒跚”，那段时间，这种感受实在是太强烈了，微笑也拯救不了内心的空虚和失落。

但当我现在回过头来看，这段经历它给我带来的利绝对大于弊。它肯定会到来，只不过是因为疫情的催化剂，早到了，幸运的是，它也提早到了。时常去激励自己运动，总没能养成习惯，就如同一个朋友之前所说的，你没有到逼不得已减肥的理由，而去年的上海闭关，恰恰成就了这个时机，让我看到，不去把控自己的身体或者放纵自己的生活，带来的结果是什么，它也让我感受到，因为胖过，我不再害怕自己胖了，即使胖了，我也知道怎么样瘦下来，而对于胖也有了新看法，胖并不可怕，可怕的是失去对身体的控制，可怕的是虚弱的身体带来的无力感，我们需要不停的使用这具终将衰老的躯壳。

说回减肥，更准确的说是，减脂这个话题，如何让自己减下去呢？

1. 调整自己的目标

将眼睛从减肥这个目标转移出去。如果一直盯着这个减肥目标，那么就会一直关注着体重的数字，体重不代表就是瘦，而且只要消耗大于摄入，身体就会自然而然的瘦下来，减肥也并不只是体重数字的减少，重要的是减少脂肪，等体脂率下来，肌肉增长，同样的体重状态下，人的精神面貌也是不一样的。日常的消耗大于摄入，人就自然而然的会瘦下来，让减肥称为快乐运动快乐生活的副产物。

病隙杂思

发表于 2023-03-07 | 分类于 杂思 | | 热度: ℃

上上周末去了长白山，没想到周日开始发热，周一赶路，紧赶慢赶到上海后又发热了好几天。

十几年没有这样生过病了，四五天之后发现自己还在发热时，真的脆弱到掉眼泪。难受是肯定的，但可能更多的是无可奈何的感觉，身体乏力，食不下咽，发热头痛，虚弱咳嗽，不知道怎样好，怎样才能不难受。

只是生了一周病，只是发了一周烧，已然对生病产生了无力感，身体已经虚弱的不行。当时躺在床上，喉咙刀割一般，很想吃个草莓，幸好前一天也买了草莓在桌上，但拿不到，必须起来，勉力起来，穿衣服穿裤子，然后腾挪到桌子旁，去拿草莓，这还是洗过的。

房间里都是外卖的盒子，每天都想勉力吃点东西下去，但是叫了外卖，最后吃一点就吃不下了，只能收拾起来放在门后，积攒几天，就都是没扔的垃圾了。有时候躺着无聊，想着要么就看看书，看不了几页，就精神乏力。呼吸也是一件挺累的事情，每当冷空气涌到喉咙口，就忍不住想要咳嗽，既咳嗽又喉咙痛，咳嗽几声，脑袋又缺氧，晕得慌。

生病实在是难受啊，窗户外再好的天气，开点窗来些风，身体就受不了，走两步就喘的不行。贯来自己不算是脆弱的，只生病到后期，却伤春悲秋起来，没来由，就感觉眼睛累，想哭，感觉全身都是发热留下来的汗，黏连一片，又不敢洗澡，也没力气洗澡。开始睡觉，就开始发热，就开始出汗，衣服全部湿透了，也不敢掀开被子去。

生病第二周，还是咳嗽，精神乏力，脑袋也仍然时不时的抽痛，没有心力干活，思考变得负累，这种负累单纯是使得脑袋痛。

怎么说呢，越来越觉得，什么都没有身体健康重要。

刚毕业的时候，还感觉自己要好好工作天天向上，多学点多做点，现在感觉月薪是最邪恶的东西之一，它束缚你的生活你的思想，让你安稳的按照它的流程来，直到你也成为流水线的一款标准产品，而我在不停的搬运和制造垃圾，信息垃圾。工作不需要贡献你的全部能力，只需要你按照它流水线的标准输出，按部就班，重要的不是你增加了多少创意，重要的是不要出错，但人不是机器，只要你做的越多，你错的必定越多。

月薪的多少也不是衡量你价值多少，也要警惕这点，因为当你把衡量自我价值的标杆拱手让人，那么你的生活你的情绪你的价值也会被牵着走。很多情绪疾病也是因此而来，你活着就是价值本身，并不是因为你找到了工作，你获得了不低的月薪，你拥有了票子车子房子，你才有价值。因为你是你，你本身的存在就是价值本身。

这可能和我所认为的生活的意义有些不太一样，我始终认为人生是没有价值的， 不是因为人生有价值我们才出生，而是出生之后我们才会想到意义，才会出现“寻找人生意义”这样的话题，实际上，人生本身可能毫无意义，只是单纯的“生存”。但这不是我们毫无价值，而是存在本身的价值。

下午上班，实在是困倦得不行，叫了咖啡外卖。

出去拿咖啡，天气明显已经凉了起来，空气微凉。路过园区的草坪，草坪也染上了昏黄，稀稀拉拉，偶尔一眼撇到了草坪那端竟然有一张石桌和几个石凳。之前还和同事说，公司好多草坪但却没一个凳子，有点遗憾，乍然间，突然看到那边角落的石凳，有一种小小的惊喜。

恍惚间，记起高中的时候，我们的校园一角也有这样一张凳子两三个桌子。那时候每个归校的周日午后，我都会在那边写作业，直到下午的自习课快开始，校园安静下来，才收拾东西往教室走去。那是我为数不多的非常享受的时光。阳光透过叶丛，洋洋洒洒的铺散一地，温暖却不炽热，也是这样的时节，地上铺着厚厚的叶子，踩上去咔哧咔哧的响，微风拂过，带来恬淡的宁静。校园像是在另一个世界，声响像是隔着一层厚厚的膜，这一隅风景，只有我一个人独占。

高三大小周时，有时候我也会留校，校园里渐渐安静下去，冬天又不适宜在那石凳上，就会搬着桌子在宿舍的阳台上，冬日的暖阳斜斜的一方，落在阳台上桌子上书面上以及我的身上，温暖惬意，一切似乎都远去了，天地间只有温暖的阳光和自己同在。

当临到小周时（只有周日半天的休息时间），我也会一个人到学校周边的图书馆，那里空旷无人，只有图书管理员一个人，在昏暗的灯光下，我会一直待着，直到关门。

那些，一个人独享的，宁静的时光里，没有高考的倒计时，没有来源于他人的交流和关心，彷佛在自己的世界里，拥有大把的安心和大把的自由。

这样想起来，那时候不止一个同学说感觉我好像很孤独，大概是因为我经常选择周末不回家留宿学校。

有时候会一个月，或者一个半月回家一次。

的确，好像不太恋家。

后来大学选择的志愿不是广东就是北京，没有省内的，也没想过附近的江浙沪；
大学很少回家，工作后也是。
